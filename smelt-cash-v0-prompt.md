# Smelt.Cash Landing Page — v0 Prompt Kit

A comprehensive prompt system for generating a production-ready Smelt.Cash landing page using v0.app. Built from the Smelt.Cash brand target profile, brand guidelines, and inspired by Aura.build's design patterns (dark gradients, glassmorphism, bold typography, smooth animations).

---

## How to Use This

1. **Start with the Full Prompt** (Section 1). Copy the entire block into v0. This generates the complete landing page in one pass.
2. **Refine by section** (Section 2). If any section needs work, copy the relevant section-specific prompt into v0 as a follow-up.
3. **Adjust style** (Section 3). Use style refinement prompts to tune the visual feel — darker, more glassmorphism, different animation behavior.
4. **Swap the hero** (Section 4). Try alternative hero section approaches to see which resonates.
5. **Remix components** (Section 5). Pull individual components out for use in other pages or experiments.
6. **Run the checklist** (Section 6). Before shipping, paste the final checklist prompt to catch issues.
7. **Read the notes** (Section 7). Tips for getting the best results from v0 with this prompt kit.

## 2. Section-by-Section Refinement Prompts

Use these after generating the full page to refine individual sections.

### Hero Section

```
Refine the hero section:
- Make the headline larger and bolder — it should dominate the viewport. Use a text gradient from white to a subtle gold on "No Gas. One Click."
- The transformation animation should be more dramatic: start with scattered colorful particles (representing altcoins on different chains) that swirl and converge into a single golden form. Use Framer Motion with staggered delays.
- Add a subtle parallax effect on the background gradient as the user scrolls.
- The trust bar should use monospace for "0.3%" and feel like a data readout, not marketing copy.
- CTA button should have a subtle golden glow/pulse animation that draws the eye without being distracting.
```

### Problem Section

```
Refine the problem section:
- Each pain point card should have a dark background with a subtle red-to-amber gradient border (not the card itself — just the border glow).
- Add a micro-animation: when each card enters the viewport, it fades in with a slight upward translate (staggered, 100ms apart).
- The icons should be line-style, geometric, in steel silver. Not filled, not colorful.
- Add a small "sound familiar?" text below all three cards in italic, lower opacity.
- Make the section feel heavy and frustrating — this is the pain the product solves.
```

### Solution Section

```
Refine the solution section:
- The three-step flow should animate sequentially when it enters the viewport: Step 1 appears, then a connecting line draws itself, then Step 2, then another line, then Step 3. Each step takes 200ms to appear.
- The "Smelt" step (Step 2) should have a molten gold glow that pulses once when it appears — this is the transformation moment.
- The before/after comparison should be interactive: a draggable slider or toggle that switches between the chaotic "before" state and the clean "after" state. The transition should feel like a satisfying transformation.
- "After" side: the USDC amount should count up from 0 to 8,942 in monospace with a Stable Green color. The APY should fade in after the counter finishes.
```

### Features Section

```
Refine the features grid:
- Cards should use glassmorphism: background rgba(255,255,255,0.03), border rgba(255,255,255,0.08), backdrop-blur-xl.
- On hover, the card's icon should glow in its accent color (gold for gasless/speed features, green for earn/yield features, silver for protection features).
- Add a subtle grid pattern or dot matrix in the section background for visual texture.
- Each card title should be in Forge White (#F8F9FA), description in Steel Silver (#BDC3C7).
- The grid should be responsive: 2x3 on desktop, 2x2+2 on tablet, stacked on mobile.
- Add a thin molten gold accent line at the top of each card.
```

### Stats Section

```
Refine the stats/social proof section:
- Animated counters should use monospace font and count up when they enter the viewport. Use a smooth easing function, not linear.
- Each stat should have a subtle label above it in small caps, steel silver, low opacity.
- The background should be a darker gradient than the surrounding sections to create visual separation.
- The testimonial marquee should auto-scroll horizontally at a slow, steady pace. Each quote in a glassmorphism pill. Pause on hover.
- Add quotation marks in molten gold before each testimonial.
```

### How It Works Section

```
Refine the How It Works section:
- Use a tabbed interface, not an accordion. Tabs styled as glassmorphism pills in a horizontal row.
- Active tab has a molten gold underline or background tint.
- Each tab content area should have an illustration on the left and text on the right (stacked on mobile).
- Illustrations should be abstract, geometric diagrams — not screenshots. Use the brand color palette.
- Transition between tabs with a crossfade (150ms).
- Add a code-like element for the fee structure: a monospace block showing "Swap Output: 10,000 USDC | Fee (0.3%): 30 USDC | You Receive: 9,970 USDC" in the Gasless tab.
```

### Final CTA Section

```
Refine the final CTA section:
- This should feel like a crescendo. The background should have a warm, golden ambient glow radiating from behind the CTA button.
- Floating ember/particle effects drifting upward, very subtle, using small golden dots with varying opacity and speed.
- The headline "Your Portfolio Is Waiting" should fade in with a slight scale-up.
- CTA button: larger than the hero CTA, with a more pronounced golden glow. On hover, the glow intensifies.
- Below the CTA, add a small trust element: "No sign-up required. Connect wallet and smelt." in steel silver, small text.

## 3. Style Refinement Prompts

### Push Darker

```
Make the overall design darker and more atmospheric:
- Background gradient should go from #0d1117 to #080b10
- Reduce glassmorphism card opacity to rgba(255,255,255,0.02)
- Increase the contrast of the molten gold accent against the darker background
- Add more depth with layered gradient overlays
- The grain texture should be more subtle (opacity 0.02)
- Text contrast should remain high — Forge White (#F8F9FA) on the dark background
```

### More Glassmorphism

```
Increase the glassmorphism effect throughout:
- Cards should have more prominent backdrop-blur (backdrop-blur-2xl)
- Add a frosted glass effect to the navigation bar when scrolled
- Feature cards should have a visible glass edge — brighter top border (rgba(255,255,255,0.12)) that fades to transparent at the bottom
- The stats section should sit on a large glassmorphism panel
- Tab content areas should have a glassmorphism container
- Ensure performance: use will-change: transform on blurred elements
```

### More Industrial / Forge Aesthetic

```
Push the visual design more toward the "Industrial Alchemy" brand concept:
- Background texture: add a very subtle metallic brushed-steel grain pattern
- Section dividers: use a thin molten gold line with a soft glow, as if metal is being heated at the seam
- The hero transformation animation should feel more like smelting: particles should glow orange/gold as they converge, as if being heated and refined
- Feature card icons should use a metallic/etched line style
- The progress flow (Connect → Smelt → Earn) should look like stages of a foundry process: raw ore → furnace → refined ingot
- Typography should feel slightly more industrial: tighter letter-spacing on headlines, heavier weights

### Reduce Animation

```
Tone down the animations for a more restrained feel:
- Remove particle/ember effects from background
- Keep scroll-triggered reveals but reduce translate distance (from 20px to 8px)
- Remove hover lift effects on cards, keep only the icon glow on hover
- Remove the CTA pulse animation — static golden glow is enough
- Counter animations should be faster (500ms instead of 1500ms)
- Remove parallax scrolling — keep backgrounds static
- The before/after section should be a static comparison, not interactive

### Light Mode Variant

```
Create a light mode alternative of the landing page:
- Background: Forge White (#F8F9FA) to light gray (#EDF0F5)

## 7. Notes for Best Results

### Prompt Strategy

- **Start with the Full Prompt.** v0 handles long, detailed prompts well. The full prompt in Section 1 gives v0 enough context to generate a cohesive page. Starting with a vague prompt and iterating wastes generations.
- **Refine one section at a time.** After the initial generation, use Section 2 prompts to fix specific sections. Don't try to change everything at once — v0 tracks changes better in focused iterations.
- **Be specific about what's wrong.** Instead of "make it better," say "the feature cards need more glassmorphism — increase backdrop-blur and add a brighter top border."
- **Reference exact colors and values.** v0 respects hex codes, pixel values, and timing values. "#F5A623" is better than "gold." "150ms" is better than "fast."

### Design Priorities

- **The before/after transformation is the most important visual on the page.** If one thing looks great, it should be the moment chaos becomes order. This is the Magician's showcase.
- **The hero headline needs to communicate gasless + one-click + multi-chain in one breath.** Users decide in 3 seconds. "Turn Altcoins Into Stables. No Gas. One Click." does this.
- **Monospace for money.** Every dollar amount, percentage, token count, and APY figure should be in monospace. This isn't a style choice — it's a trust signal. Precision matters when money is on the line.
- **Molten Gold is precious.** Use it for the Smelt CTA, for transformation moments, and for the brand's golden accent. If everything is gold, nothing is. Reserve it for moments of action and alchemy.

### Technical Tips

- v0 generates Next.js App Router code by default. The prompts are written for this stack.
- If animation performance is poor, use the "Reduce Animation" prompt from Section 3 as a follow-up.
- The particle/ember effects are the most likely to cause performance issues on mobile. The full prompt includes a note about disabling them on mobile, but you may need to reinforce this in a refinement pass.
- Framer Motion's `useReducedMotion` hook should be present for accessibility. If v0 doesn't include it, ask for it in a refinement pass.
- For the animated counters, request that they trigger once using Intersection Observer and don't re-trigger when scrolling back up.

### Common v0 Issues to Watch For

- **Overusing accent colors.** v0 sometimes applies the gold accent too broadly. Use the checklist prompt to catch this.
- **Generic CTA text.** v0 may default to "Get Started" or "Learn More." Always specify the exact CTA text: "Smelt Your Portfolio."
- **Corporate tone creep.** Words like "revolutionize," "seamlessly," "cutting-edge" can sneak in. The checklist prompt catches these.
- **Missing monospace on numbers.** v0 sometimes uses the body font for financial figures. Specify monospace explicitly.
- **Slow animations.** v0's default Framer Motion timing can be leisurely. Specify 150-250ms in the prompt and reinforce in refinement.
- **Light section backgrounds.** The page should be consistently dark. v0 sometimes introduces lighter sections for visual variety — push them back to the dark gradient range.

### Iteration Workflow

1. Paste the Full Prompt → review the initial output
2. Identify the weakest section → paste the corresponding refinement prompt
3. Apply one style refinement prompt if the overall feel needs adjustment
4. Run the Final Checklist prompt to catch inconsistencies
5. Test on mobile viewport (375px) — most issues appear here
6. If the hero doesn't feel right, try one of the Alternative Hero prompts as a fresh generation
